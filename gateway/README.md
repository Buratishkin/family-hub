# Gateway

Единая HTTP-точка входа в backend FamilyHub. Принимает запросы клиента и проксирует их в нужный сервис.

## Что делает

- Направляет запросы авторизации, семей, задач, адресов, питания и уведомлений в соответствующие сервисы.
- Передаёт заголовки, включая Authorization, тело запроса и ответ сервиса.
- Направляет остальные запросы в корневое BFF-приложение.

Проверки JWT и бизнес-прав выполняются в сервисах. Gateway не хранит доменные данные и не использует PostgreSQL или Kafka.

## Адреса

- Точка входа: http://localhost:8082
- Health: GET http://localhost:8082/gateway/health
- Настройки: [application.yaml](src/main/resources/application.yaml)
